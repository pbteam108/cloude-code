# cloude-code

シンプルな Slack ライクのチャットアプリ（バニラ HTML / CSS / JavaScript）です。
ビルドツールや npm パッケージは一切不要で、`index.html` をブラウザで開くだけで動作します。

## 主な機能

- **サイドバー**: チャット検索ボックスと、チャンネル / ダイレクトメッセージの一覧。
- **メインエリア**: 選択中のチャットのタイトルとメッセージスレッドを表示。
- **メッセージ送信**: 入力欄からメッセージを追加できます（デモ用にメモリ上でのみ保持）。

### 「マイチャット」検索 → 川村真緒のチャットを表示

このアプリの目玉機能です。検索ボックスに **「マイチャット」** と入力すると、
**川村真緒 (Kawamura Mao)** のチャットが自動的に選択・表示されます。

判定は緩やかに行われ、以下のいずれも「マイチャット」として扱われます
（前後の空白は無視、大文字小文字も区別しません）:

- `マイチャット`
- `まいちゃっと`
- `mychat`
- `my chat`

それ以外のキーワードでは、チャット名・参加者名・メッセージ本文に対して
通常の絞り込み検索を行います。

#### マッピングの変更方法

「マイチャット」がどのチャットを開くかは `app.js` の以下の箇所で定義しています。
ここを書き換えるだけで、対象チャットやキーワードを簡単に変更できます。

```js
const MY_CHAT_TARGET_ID = "kawamura-mao";
const MY_CHAT_ALIASES = ["マイチャット", "まいちゃっと", "mychat", "my chat"];
```

## 実行方法

ビルド不要です。`index.html` をブラウザで開いてください。

```sh
# 例: ファイルを直接開く（OS により異なります）
open index.html      # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```

## ファイル構成

- `index.html` — ページ構造（サイドバー + メインエリア）
- `styles.css` — チャットアプリ風のスタイル
- `app.js` — データモデル、描画、検索ロジック
